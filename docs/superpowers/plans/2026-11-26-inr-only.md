# INR-only Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Vestora supports INR only — the currency switcher, live-FX fetch, conversion machinery, US Treasuries machinery, cross-currency hedge/concentration analysis, and FX Risk Radar card are deleted; the sample's US-equity holding is re-denominated to INR at the pinned 86.50 rate; saved foreign-denominated portfolios migrate on load so no figure a visitor sees changes.

**Architecture:** Five staged passes, each leaving the suite green: (1) data + migration groundwork with `convertCurrency` still live, (2) FX-system deletion, (3) Treasuries/hedge machinery deletion, (4) component `baseCurrency`-prop strip + `convertCurrency` collapse to identity amounts + chat import simplification, (5) `CurrencyCode = 'INR'` type narrowing — at which point tsc itself flags every surviving `=== 'USD'` comparison and dead format branch as a compile error, making the sweep mechanical.

**Tech Stack:** React 19 + TypeScript (tsc --noEmit is lint AND the narrowing enforcement), Tailwind v4 named tokens, node:test via tsx (`node --import tsx --test src/demo/*.test.ts src/utils/*.test.ts`), Playwright MCP for browser verification.

**Spec:** `docs/superpowers/specs/2026-11-26-inr-only-design.md` (approved 2026-11-26, builder-check resolutions folded in)
